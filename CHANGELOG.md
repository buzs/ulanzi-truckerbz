# Changelog

## 0.2.0

- Initial public distribution of Trucker Bz for Ulanzi D200.
- Added ETS2/ATS telemetry actions for speed, fuel, RPM, trip, rest and damage information.
- Added configurable controls for lights, beacon, wipers, windows, suspension, retarder and trailer hookup.
- Added dynamic property inspector support for per-button settings.
- Public repository ships the final `com.buzs.truckerbz.ulanziPlugin` folder without source code.
- Public repository excludes `node_modules`; run `npm install` inside the plugin folder when using a clone.
- GitHub Release ZIP remains the recommended install artifact for end users.
